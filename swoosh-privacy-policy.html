Swoosh Privacy Policy

App: Swoosh (com.expxlabs.swoosh)
Provider: expxlabs
Effective: July 30, 2026 · Last updated: July 30, 2026

Summary: Swoosh collects no personal information and transmits no data off your device. Swoosh does not declare the internet permission (android.permission.INTERNET) at all, so it is technically incapable of sending data to any server. It contains no advertising, analytics, or crash-reporting SDKs, and there are no accounts or backend services.

1. Information we collect

Swoosh does not collect or transmit any personal or device information. The developer has no access to your data. Specifically, Swoosh does not collect, transmit, sell, or share:

  • Personally identifiable information such as name, email address, or phone number
  • Account or login credentials (Swoosh has no account feature)
  • Contacts, messages, call logs, photos, or files
  • Location data
  • Screen content, typed text, or passwords
  • Advertising identifiers (AAID) or persistent device identifiers
  • Usage analytics, event logs, or crash reports

2. Information stored only on your device

Swoosh stores the settings you configure in app-private storage on your device (Android SharedPreferences). This data never leaves the device and is not accessible to other apps.

  • Edge panel slot layout and action bindings
  • Favorite apps (package names)
  • Widget panel configuration
  • Excluded apps where handles are hidden (package names)
  • Presentation settings such as handle position, size, and opacity, interaction timing, icon style, and layout tuning

This data is removed from the device when you uninstall the app.

4. Accessibility service data-use disclosure

Swoosh uses the Android accessibility API for two purposes only: performing the system actions you explicitly select, and identifying the current app so handles can be hidden in apps you exclude.

  • Swoosh's accessibility service is configured with canRetrieveWindowContent="false", so it cannot read screen content. It does not read, collect, store, or transmit on-screen text, typed input, or passwords.
  • The only accessibility event it subscribes to is window state change (typeWindowStateChanged), and the only value it uses from it is the package name of the foreground app. That value is used immediately to decide handle visibility and is not stored.
  • No information obtained through the accessibility API is transmitted off the device, shared with third parties, or used for advertising, analytics, or profiling.
  • Actions are performed only in response to your direct gesture or tap; Swoosh never initiates actions on its own.

5. Third parties and external services

Swoosh bundles no third-party SDKs or external services. There is no ad network, analytics tool, crash reporter, or payment module, and no data is sent to any developer-operated server. Consequently, no personal information is shared with third parties.

6. Backup and settings export

User-initiated settings export / import

Swoosh can export its settings to a JSON file and import them back. This happens only when you initiate it, and the file is written to a location you choose through the Android Storage Access Framework. The file contains only the settings listed in section 2 and no personal information. Managing and sharing that file afterward is your responsibility.

Android Auto Backup

Swoosh allows Android Auto Backup. As a result, the settings listed in section 2 may be backed up to your own Google account and restored when you reinstall the app or set up a new device. This backup is performed by the Android operating system, not by Swoosh, and the developer cannot access its contents; that data is handled under Google's privacy policy and backup terms. You can disable backup in your device's system settings.

7. Children's privacy

Swoosh is not directed at children and collects no personal information from any user, regardless of age.

8. Data retention and deletion

Because Swoosh stores no data on any server, there is no server-side data to request deletion of. Settings stored on your device can be removed as follows:

  • Uninstall the app — all Swoosh settings on the device are removed with it.
  • System Settings → Apps → Swoosh → Storage → Clear data
  • You can revoke the accessibility service, display-over-other-apps, and usage-access permissions individually in system settings. Revoking a permission disables only the corresponding feature; the rest of the app keeps working.

9. Security

All Swoosh data is kept in app-private storage on the device, isolated from other apps by the Android application sandbox. Because there is no network transmission, there is no exposure of data in transit.

10. Changes to this policy

If this policy changes, we will update this page and revise the "last updated" date above. Any material change to how data is handled will also be noted in the app's release notes.
