약먹기 / Take Meds

Privacy Policy

Last updated: March 23, 2026

약먹기 / Take Meds helps users track daily medication intake and interact with an Android home screen widget.

Developer

  • Developer name: expxlabs
  • Contact email: mutna@expxlabs.com

What data the app handles

The app stores the following information on the user’s device:

  • medication names entered by the user
  • medication taken / not taken status
  • medication order
  • last reset date and time used for the daily checklist

How the app uses this data

The app uses this information only to:

  • show the user’s medication list
  • let the user mark medications as taken or not taken
  • show the same status in the Android home screen widget
  • reset the daily checklist based on the user’s app actions

Data collection and sharing

The app does not send user-entered medication data to the developer or to third parties.

  • No account is required.
  • No cloud sync is provided.
  • No analytics SDK is included.
  • No advertising SDK is included.
  • No medication data is shared with third parties.

Storage

Medication data is stored locally on the device using Android local app storage.

The app disables Android backup for this data so that medication records are not automatically backed up through Android system backup by default.

Data retention and deletion

Data remains on the device until the user changes or removes it.

Users can:

  • edit medication names
  • delete medication items
  • clear taken marks
  • uninstall the app to remove locally stored app data from the device

Security

The app is designed to keep medication list data on-device only.

Reasonable technical measures in the app include:

  • local-only storage for medication entries
  • no built-in network transmission of medication data
  • Android backup disabled for stored medication data

Children

The app is not specifically directed to children.

Changes to this policy

This privacy policy may be updated if the app’s data practices change.

If the policy changes, the updated version will be published at the same public URL with a new effective date.

Contact

If you have questions about this privacy policy, contact mutna@expxlabs.com.
